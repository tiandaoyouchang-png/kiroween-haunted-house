# Kiroween Haunted House

Kiroween 2026 hackathon entry (Frankenstein track). Status: repository scaffold only — no business code yet.

The submission is a new haunted-house web app built during the submission period (Oct 30 – Dec 4, 2026). Wondful AI Renderer, the open-source Blender plugin for white-model-to-styled-scene rendering, is a pre-existing component created before the submission period and is disclosed here as such; it is not presented as built during the period.

First model: Lantern from the Khronos glTF Sample Assets. License: to be confirmed against the model's own page before release.

First milestone: upload a white model, generate a haunted-house scene, share the result page.
